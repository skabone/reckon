# Reckon

**Mental math, trained like a sport.** A single-file trainer: eight skills
(addition, subtraction, multiplication, division, percentages, squares,
fractions, estimation) on a gated per-skill ladder — a placement check sets
your real starting levels, practice climbs you within a level, and a 10-question
Level Test (8/10 to pass) is the only way up. A coach explains the fastest
technique for the exact numbers you missed, 19 lessons teach the classic
mental-math tricks with visual explainers, and your rating (150–2400) maps to
grade stages and SAT/GRE/ACT fluency estimates — always labeled as calibrated
estimates, never official scores.

**Use it:** https://skabone.github.io/reckon/ — install it from your browser
(Add to Home Screen on a phone; Install app / Add to Dock on a computer) and it
works offline. Everything is stored locally in your browser: no account, no
server, no tracking.

This site is a generated build of a personal project; the app is one HTML file
with no dependencies beyond Google Fonts.
